Try with sample assets

Download the matched sample CT/PET pair from Settings first. These examples contain identifiers and instructions, not image data.

  1. In Settings, download both volumes of the matched sample CT/PET pair.
  2. Download an example below and save it in the VoxelVision folder in Files. Use trial-manifest.json for a trial or batch-manifest.json for a batch.
  3. For a transform, load CT as fixed A and PET as moving B, then choose Load Transform File. For a trial, tap the main-page banner, then Start. For a batch, first save a registration with anchor pairs in that same direction, then open Logs & Feedback → Research Batch.
  4. Export the registration to finish a trial step. Batch results are saved to Research/Runs.

Write your own files

These editing templates contain explicit REPLACE_WITH placeholders. Replace every placeholder before importing. Copy complete image keys from image details; keys are not filenames. JSON requires double quotes and cannot contain comments or trailing commas. Field explanations are provided here and in the downloadable instructions.

Trial template

Two ordered pairs illustrate the structure. Replace the study ID, labels, and image keys. Duplicate or remove entries as needed; trialID and order must each be unique. Save the finished file as trial-manifest.json.

From template to your own run

  1. Import your images. For a batch, create and save each registration with anchor pairs first.
  2. Download the matching template. Copy the complete fixed and moving image keys from image details, then replace every REPLACE_WITH placeholder. Duplicate or remove pair entries as needed.
  3. Keep schema values unchanged and IDs unique. In a trial, keep order values unique too. Check JSON for double quotes, no comments, and no trailing commas. Expand the field reference below for optional settings.
  4. Save the edited file as trial-manifest.json or batch-manifest.json in the VoxelVision folder in Files. Keep one active file of each name. For a transform, replace all numeric placeholders and save as .tfm.
  5. Run a trial from the main-page banner, a batch from Logs & Feedback → Research Batch, or load a transform from the registration panel. Trial steps complete when you export; batch results go to Research/Runs.
Manifest field reference
FieldHow to customize
schema / schemaVersionKeep the values in the matching template unchanged.
studyID / runIDIdentify your trial protocol or batch run. Use a new runID for a new independent run.
trials / configsOne entry per pair. Duplicate or remove entries. Trials guide interactive work; configs select saved registrations for batch execution.
trialID / configIDUnique within the corresponding file.
order / caseLabelTrial-only: unique integer order, presented ascending, and a neutral label shown to the operator.
fixedUniqueKey / movingUniqueKeyCopy full keys from image details. Both cases must be imported. Batch configs also require a saved registration with anchors in that fixed/moving direction.
allRegistrationsfalse selects only listed configs. true expands all saved registrations with anchors; use an empty configs array if you want only that set.
benchmark.repeatCountRepetitions per input in benchmark mode; the template uses 3. Omit the benchmark object when unused.
factors (optional)Trial-only string-to-string coded labels, preserved in exported records. Keep reference truth and code-to-condition mappings outside the operator-facing manifest.

To process all saved registrations with anchors, use the all-registrations batch example. The selected-pair template uses library keys; do not add anchorsFile to the same config.

Transform parameter reference

Parameters contains nine row-major matrix entries followed by three translation components in millimeters. FixedParameters contains the three-component center in absolute LPS millimeters. The affine mapping is y = M(x − c) + c + t.

VoxelVision expects the ITK fixed-to-moving resampling transform in absolute LPS coordinates. A moving-to-fixed modeling transform must be inverted; a RAS transform also needs coordinate conversion. A FSL/FLIRT .mat is not an ITK .tfm.

Interoperability

VoxelVision packages

Use VoxelVision packages for workflows with other mobile devices running VoxelVision, transferring images and annotations between devices.

Export a sample case to create an importable example with your own annotations. VoxelVision Case Package creates a .vvcase with images and annotations. Custom can export .vvanno (annotations only) or .vvimage (images only). Import via Import Image, drag and drop, or Open With. Annotation-only packages need their matching image case in the library.

Work with 3D Slicer and ITK-SNAP

Use these export formats for workflows that combine VoxelVision on your mobile device with 3D Slicer or ITK-SNAP on a computer.

Choose Other in Export for a zip with a NIfTI volume, Slicer-compatible Markups JSON, and an NRRD or NIfTI label map. CSV reports are exports, not annotation import templates.
